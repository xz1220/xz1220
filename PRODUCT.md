# GitHub profile

## Register

brand

## Users and purpose

Visitors to Daniel Xing's GitHub profile should be able to read his personal details at a glance, on desktop and mobile.

## Confirmed direction

The user selected the original light Personal Notes concept: white background, red labels, a serif greeting and fine separators. Preserve that direction when refining the typography.

Show only Name, Age, Work, OS, Editor, Languages and Skills, followed by the existing contact links. Do not add project summaries or a duplicate text section.

## Design principles

- Make field labels as easy to read as their values.
- Keep a coherent serif/sans pairing and use weight and color for hierarchy.
- Judge sizing at GitHub's rendered column width, not only the SVG's natural size.
- Keep motion subtle and let the content settle for reading.

## Accessibility

Use strong text contrast, descriptive image alternatives and a reduced-motion style. Ensure desktop and mobile layouts have no clipped text.
